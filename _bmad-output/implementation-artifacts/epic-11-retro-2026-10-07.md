## 2. Điểm mạnh (What went well)

1. **PostgreSQL GiST Exclusion Constraint làm Single Source of Truth** — `daterange(check_in_date, check_out_date, '[)')` với `WHERE status IN ('pending','confirmed','completed')` giúp khóa/nhả phòng hoàn toàn tự động ở tầng DB, không cần custom RPC hay cronjob nhả phòng tức thì.
2. **Thư viện dùng chung `src/lib/eco-tourism/availability.ts`** — đóng gói logic kiểm tra tính khả dụng, overlap ngày, pending expiration, loại trừ `room_blocks` thành một module trung tâm cho Client, Server Components và API Route Handlers.
3. **Server-authoritative pricing** (`calculate-price` + `calculateBookingPrice`) — triệt tiêu price tampering; frontend chỉ debounce 300ms gọi endpoint định giá.
4. **Public PII-safe offline voucher** (`/eco-tourism/voucher/[code]`) — khách vãng lai nhận diện tại điểm lưu trú không cần tài khoản CRM.
5. **Code review nghiêm ngặt** — phát hiện kịp thời query join sai làm hỏng CRM (11.6), off-by-one calendar (11.8), race condition khi hủy phòng (11.5).
6. **Kỷ luật kiểm thử** — test tăng trưởng đều qua từng story; có E2E thực tế trên luồng nghiệp vụ.

## 3. Thách thức (What didn't go well)

1. **Schema drift:** `architecture.md` ghi `lots.capacity` nhưng DB thực tế không có; `lots` thiếu luôn cột `images` → phải migration `20260907000200_eco_tourism_lot_images_and_schema_fixes.sql`. 4/8 stories vấp lỗi này.
2. **Thiếu cột giữa chừng:** `room_bookings` thiếu `payment_claimed_at` → migration nóng `20260908000001`.
3. **Next.js 15/16 async APIs:** `searchParams`/`params` là Promise — phải `await` trước khi đọc; `useSearchParams` cần Suspense boundary trong App Router.
4. **SSR crash với thư viện window-dependent:** `react-leaflet` crash server component → bắt buộc `next/dynamic { ssr: false }`.
5. **Ngữ nghĩa daterange nửa mở `[)`:** overlap check phải dùng bất đẳng thức nghiêm ngặt `check_in < checkOut && check_out > checkIn` — sai một dấu là khóa nhầm phòng.

## 4. Key Insights (Bài học)

1. **Audit schema DB thực tế trước khi viết query** — không tin tài liệu architecture cũ. Áp dụng ngay cho Epic 12: schema `products`/`store_orders` là mới hoàn toàn.
2. **Ngày đặt phòng luôn theo chuẩn nửa mở `[)`** — khách trả phòng sáng hôm nay thì khách khác nhận phòng được chiều hôm nay.
3. **Component phụ thuộc `window` phải dynamic import không SSR** — quy tắc cứng cho mọi thư viện map/chart.
4. **Polling > Realtime cho guest flow:** subscribe `postgres_changes` vào `room_bookings` sẽ lộ PII cho ai có mã đơn — polling qua endpoint đã strip PII là lựa chọn đúng về bảo mật (chốt trong đợt dọn TD-03).
5. **XSS khi inject SSR data vào JSON-LD:** luôn `.replace(/</g, '\\u003c')`.
